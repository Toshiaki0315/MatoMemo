# MatoMemo

macOS (Apple Silicon) 向けの、ローカルで動く思考整理ホワイトボードアプリです。
付箋・図形・画像・テキストをキャンバスに自由に配置し、コネクタで結びつけて
考えをまとめられます。データはすべてローカルファイルとして保存され、
外部サーバーとの通信は行いません。

## 特徴

- **完全ローカル**: ボードは単一の `.matomemo` ファイル（JSON）として保存・読み込み
- **軽量ネイティブ**: Tauri 2 によりアプリサイズは約 3.4MB
- **多様なアイテム**: 付箋（パステル 6 色）／矩形・円／画像（PNG・JPG・BMP）／テキスト
- **コネクタ**: 直線・折れ線・曲線でアイテム同士を接続。アイテム移動に追従
- **重なり順の制御**: 最前面へ／最背面へ／一つ手前へ／一つ奥へ

## 使い方

| 操作 | 方法 |
|---|---|
| アイテムを追加 | 下部ツールバーのボタン |
| 選択 | クリック（Shift / ⌘ クリックで追加選択） |
| 移動 | ドラッグ |
| サイズ変更 | 選択したアイテムの四隅・辺のハンドルをドラッグ |
| テキスト編集 | ダブルクリック |
| 削除 | Delete / Backspace、または右クリックメニュー |
| 重なり順の変更 | 右クリックメニュー |
| 線でつなぐ | アイテムを選んで「接続」を押し、相手をクリック（未選択なら 2 つ順にクリック） |
| 線を選ぶ | 線をクリック。種類・矢印の変更と削除ができる |
| 接続先を変える | 選んだ線の端点を別のアイテムへドラッグ |
| テキストの配置 | アイテムを選ぶと左上に出る設定（横位置・縦位置） |
| 複数選択 | 空白部分からドラッグして範囲で囲む（Shift 併用で追加） |
| パン | 二本指スクロール、または Space + ドラッグ |
| ズーム | ⌘ + スクロール、トラックパッドのピンチ、右上のボタン |

### キーボードショートカット

| キー | 操作 |
|---|---|
| ⌘N | 新規ボード |
| ⌘O | 開く |
| ⌘S | 保存 |
| ⇧⌘S | 別名で保存 |
| ⌘Z / ⇧⌘Z | 元に戻す / やり直す |
| Space + ドラッグ | キャンバスを動かす |
| Delete / Backspace | 選択中のアイテムを削除 |
| Escape | テキスト編集・メニューを閉じる |

## 保存形式

ボードは拡張子 `.matomemo` の JSON ファイルとして保存されます。画像は
data URL として埋め込まれるため、1 ファイルだけで内容が完結します。
スキーマバージョンを持ち、読み込み時にすべてのフィールドを検証します。

未保存の変更があるまま新規作成・ファイルを開く・ウィンドウを閉じる操作を
行うと、確認のダイアログが出ます。

## Markdown への書き出し

「Markdown 出力」で、ボードの内容を箇条書きの Markdown ファイルとして
書き出せます。線のつながり（from → to）を親子関係とみなして入れ子にします。

```markdown
# 検討メモ

- 課題
  - 原因
    - 対策
```

線が循環していたり、一つのアイテムが複数の親を持っていたりする場合も、
二度目以降は「（再掲）」として 1 行だけ書き出すので、出力が無限に
膨らむことはありません。どのアイテムも必ず 1 度は書き出されます。


## アーキテクチャ

TDD を成立させるため、ドメインロジックとプラットフォーム依存コードを分離しています。

```
src/
  domain/     純 TypeScript のドメインロジック（DOM / Tauri 非依存）
  render/     Canvas 2D への描画
  platform/   Tauri 依存を閉じ込めるアダプタ層
  store/      アプリケーション状態 (Zustand)
  ui/         React コンポーネント
src-tauri/    Tauri (Rust) シェル
```

`domain/` は副作用のない純関数のみで構成され、カバレッジ 100% を維持します。
詳しい選定理由は [TECH_STACK.md](./TECH_STACK.md) を参照してください。
